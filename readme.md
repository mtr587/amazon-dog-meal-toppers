# Best Dog Meal Toppers

A static affiliate website for Amazon Associates, showcasing the best dog meal toppers with research-backed information.

Built with vanilla HTML/CSS — no frameworks, no build step, no bloat.

## Deploy to GitHub Pages

1. Fork or push this repo to `jamesma06/dog-meal-toppers`
2. Go to **Settings → Pages**
3. Set source to **Deploy from branch: main /root**
4. Visit `https://jamesma06.github.io/dog-meal-toppers/`

Or use the `docs/` folder approach — just copy `index.html` into `docs/` and point Pages there.

## Affiliate Links

All Amazon links use the tag `jamesma06-20`. Update `index.html` if you need a different tag.
